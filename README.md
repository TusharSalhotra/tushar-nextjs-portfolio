# Tushar Salhotra — Next.js Portfolio

A responsive, SEO-ready portfolio built from the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Personalize before deployment

1. Add your real LinkedIn URL in `app/page.tsx`.
2. Add your GitHub URL in `app/page.tsx`.
3. Put your PDF resume at `public/tushar-salhotra-resume.pdf`.
4. Add real project screenshots under `public/projects/`.
5. Update metadata in `app/layout.tsx` if you want a custom domain/description.

## Deploy

This project is ready for Vercel or any Node-compatible Next.js host.
